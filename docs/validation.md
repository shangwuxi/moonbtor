# 验证方法与可复现范围

## 不同层次不能互相替代

- 单元/对抗测试：解析错误、sort、引用、空输入、资源预算、输入不可变性、帧同步、除零、符号边界、宽值、嵌套数组读写/CNF、标准 witness 的声明/帧/值校验及闭环条件。
- 原始 Python 整数参考与有限枚举：保留基础算子、独立 CNF 小实例枚举及小系统可达性测试。
- generate_standard_oracles.py：14 类新增标准算子，1/3 位全枚举和32/64位边界与固定随机，共1876组具体值；其中952组窄位输入还检查正确 CNF SAT、错误 CNF UNSAT、typed 解码重放。
- z3_interop.py：Z3 4.15.4 独立核对1876组期望值；实际执行数组 DIMACS→Z3 SAT→完整赋值→MoonBit typed 解码→独立重放。Z3与Python参考应同时匹配，而不是拿实现本身当参考。
- upstream_compat.py：固定 Boolector/btor2tools 提交 e6941e37e056084ab6e51c5c1eee6233089a330d 的例子，仅检验模型解析。它不是 witness 互通测试；独立格式对照与双向 witness 验证须分别记录，不能由本项目自往返替代。
- CI：固定官方编译器及核心包摘要，四后端严格检查、构建、测试、所有下游样例；JS 独立 Z3 互通、wasm-gc覆盖率。公开CI证据必须绑定当前发布SHA。
- 发布：精确版本消费者，在空 MOON_HOME、无凭据和无旧包缓存环境下载，运行中文README与新样例，并逐文件比较发布源码。

## 执行

参见根 README 命令。生成测试后执行 moon info、moon fmt；CI要求重新生成不产生差异。测试数与覆盖率使用实际运行结果，不将样本数、断言数等同测试用例数。局部跑通不等于全后端通过。

## 当前限制

覆盖率不是正确性证明；上游解析通过不证明求解等价；测试没有证明所有位宽与所有模型；DPLL仅面向有限小实例。对复杂数组/乘除模型的明确资源拒绝是预期行为。witness 自往返只证明本库读写一致，外部兼容结论还需固定版本上游或独立消费者验证。嵌套数组端口无法由常用单层 witness 行语法表达；无界算法也未实现。
